Datensicherung

Backups können in iCloud Drive gespeichert und auf einem anderen Gerät importiert werden. Dies ist eine manuelle Übertragung, keine automatische Synchronisierung.

Speicherstatus wird geprüft.

Gerätewechsel / Datenabgleich

Auf dem ersten Gerät Backup exportieren, Datei über iCloud Drive auf das zweite Gerät übertragen und dort importieren. Beim Import werden die vorhandenen Daten durch die Datei ersetzt. Vorher auf beiden Geräten ein Backup anlegen.

Datenschutz

Deine Einträge liegen im Browser dieses Geräts. GitHub Pages speichert keine Trainings- oder Ernährungsdaten. Automatisches iCloud-/PC-Sync benötigt später einen separaten Cloud-Dienst mit Anmeldung.

Mahlzeit hinzufügen

Leere Werte werden für bekannte Lebensmittel geschätzt. Unbekannte Werte bleiben offen.

Ohne eigenen KI-Dienst arbeitet die lokale Schätzung offline. Keine API-Schlüssel in diese App eingeben. KI-Schätzungen sind Näherungswerte.
